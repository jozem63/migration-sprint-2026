# Leadliste Dunkelbereich

## Ziel

Arbeitsliste fuer potenziell betroffene Vereine/Organisationen, die oeffentlich noch Hinweise auf `sportverein-homepage.de` zeigen und nicht bereits im Migration-Sprint beauftragt sind.

## Regeln

- Nur oeffentliche Website-/Vereinsdaten erfassen.
- Keine privaten personenbezogenen Daten ins Repo uebernehmen.
- Jeden Treffer gegen `sprint-status.md` abgleichen.
- Vor Ansprache rechtlich/organisatorisch pruefen.
- Keine Massenmail ohne Einwilligung.

## Statuswerte

| Status | Bedeutung |
|---|---|
| offen | noch nicht geprueft |
| pruefen | manuelle Verifikation noetig |
| qualifiziert | passt fachlich fuer Vertriebsaktion |
| nicht passend | kein relevanter Sportverein / kein Bedarf |
| bekannt | bereits im Sprint oder bekanntes Projekt |
| angesprochen | Vertriebsaktion erfolgt |

## Prioritaet

| Prio | Bedeutung |
|---|---|
| A | aktiver Sportverein mit eigener Domain und sichtbarem sportverein-homepage.de-Hinweis |
| B | Verein/Organisation mit eigener Domain, Bedarf moeglich |
| C | Subdomain oder unklarer Betrieb, manuell pruefen |
| D | unklar oder vermutlich nicht passend |

## Pruefschritte je Lead

- [ ] Website erreichbar
- [ ] sportverein-homepage.de-Hinweis sichtbar
- [ ] Sportverein oder passender Verein
- [ ] eigene Domain oder Subdomain geklaert
- [ ] Aktualitaet der Website grob geprueft
- [ ] bestehende Projektliste abgeglichen
- [ ] Prioritaet gesetzt
- [ ] empfohlene Ansprache formuliert

## Ansprache-Vorbereitung

Pro qualifiziertem Lead vor Ansprache notieren:

- konkreter technischer Hinweis
- warum Handlungsbedarf besteht
- kurzer Nutzen von zContent/zLiga
- Angebot: unverbindlicher Kurzcheck
- empfohlener Kontaktweg nach rechtlicher Pruefung
