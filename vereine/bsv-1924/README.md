Projektordner fuer die Migration des Breitenfelder Sportverein von 1924 e.V. in zContent und die zLiga-Struktur.

## Ausgangsdaten

- Alte Website: https://www.bsv1924.de/
- Vorlage: Vorlage A
- Status: in Arbeit
- Grundsatz: 1:1-Uebernahme, keine Aenderungen ohne Rueckfrage
