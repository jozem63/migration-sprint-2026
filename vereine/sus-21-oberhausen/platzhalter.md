# CMS-Platzhalter SuS 21 Oberhausen

## Pflicht-Platzhalter

| Platzhalter | Inhalt |
|---|---|
| `%TOPMENU%` | `topmenu.html` |
| `%FOOTER%` | `footer.html` |
| `%SPONSOREN%` | `box-sponsoren.html`, Sponsor-Logos |

## Layout- und Sidebar-Platzhalter

| Platzhalter | Verwendung |
|---|---|
| `%SIDEBAR%` | Generische Sidebar fuer Verein, Partnerschaft, Breitensport |
| `%SIDEBAR_SENIOREN%` | Senioren-Teamseiten |
| `%SIDEBAR_FRAUEN%` | Frauen / Damen |
| `%SIDEBAR_JUGEND%` | Jugend-Teamseiten |
| `%SPONSORBOX%` | Partner-Box in Sidebars |
| `%INFOBOX%` | Sidebar-Infos |
| `%INFOBOX-START%` | Startseiten-Infobox |
| `%ONLINE-SPONSOR%` | Sponsor Startseite |
| `%ONLINE-SPONSOR-SENIOREN%` | Sponsor Senioren-Sidebar |
| `%ONLINE-SPONSOR-JUGEND%` | Sponsor Jugend-Sidebar |

## Widgets

| Platzhalter | Verwendung |
|---|---|
| `%NEWS-SLIDER%` | News-Slider Startseite |
| `%WIDGET-STAIGETV%` | Staige.tv |
| `%WIDGET-ID-SCHLEUSE1%` | fussball.de Widget Schleuse I |
| `%WIDGET-ID-SCHLEUSE2%` | fussball.de Widget Schleuse II |
| `%VIDEO-01%` | YouTube / Schleusepark Video |

## Hinweis

Widget-Code nie direkt in TinyMCE einbauen. Externe Widgets werden als CMS-Platzhalter gepflegt.
