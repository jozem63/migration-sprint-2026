# Templates SuS 21 Oberhausen

## CMS-Templates

Aus `Projektdateien/PROJEKTDOKU-SUS21.md`:

| Datei | Verwendung |
|---|---|
| `index.html` | Startseite |
| `index-default.html` | Seiten ohne Sidebar |
| `index-sidebar.html` | Seiten mit generischer Sidebar |
| `index-senioren.html` | Mannschaftsseiten Senioren |
| `index-frauen.html` | Damen-Mannschaft |
| `index-jugend.html` | Mannschaftsseiten Jugend |
| `index-contact.html` | Kontaktformular |
| `index_news.html` | News-Artikel |

## Template-Quellen im ZIP

- `UPLOUD/`
- `Projektdateien/sus21-templates/`
- `Projektdateien/zusammenstellung/UPLOUD/`

## Wichtige Platzhalter je Template

- `index.html`: `%NEWS-SLIDER%`, `%WIDGET-ID-SCHLEUSE1%`, `%WIDGET-ID-SCHLEUSE2%`, `%INFOBOX-START%`, `%WIDGET-STAIGETV%`, `%ONLINE-SPONSOR%`, `%SPONSOREN%`
- `index-default.html`: `%CONTENT%`, `%SPONSOREN%`
- `index-sidebar.html`: `%CONTENT%`, `%SIDEBAR%`, `%SPONSOREN%`
- `index-senioren.html`: `%CONTENT%`, `%SIDEBAR_SENIOREN%`, `%SPONSOREN%`
- `index-jugend.html`: `%CONTENT%`, `%SIDEBAR_JUGEND%`, `%SPONSOREN%`
- `index-contact.html`: `%CONTENT%`, `%SPONSOREN%`
